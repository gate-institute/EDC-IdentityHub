# EDC IdentityHub

This is a fork of the [EDC IdentityHub](https://github.com/eclipse-edc/IdentityHub)
repo and contains gate-specific changes for testing and deployment purposes.

The `gate/0.18.0` branch is the main branch used for GATE deployments.
It contains changes to EDC's `v0.18.0` tag
(ref. [60091fb](https://github.com/eclipse-edc/IdentityHub/tree/60091fb68eb7de0eb2f290281ec4af44cc3e467f)),
most of which are gate-specific changes inherited from the EDC Connector
(listed [here](https://github.com/gate-institute/EDC-Connector)).

For a detailed view of *all* changes, see the
[diff](https://github.com/gate-institute/EDC-IdentityHub/compare/v0.18.0...gate/0.18.0?expand=1).

## Quick start

Please refer to Eclipse's
[Quick Start](https://github.com/eclipse-edc/IdentityHub/tree/v0.18.0?tab=readme-ov-file#quick-start)
guide for IdentityHub.
