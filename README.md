# EDC IdentityHub

This is a fork of the [EDC IdentityHub](https://github.com/eclipse-edc/IdentityHub)
repo and contains gate-specific changes for testing and deployment purposes.

The `gate/0.15.1` branch is the main branch used for GATE deployments.
It contains changes to EDC's `v0.15.1` tag
(ref. [c46a1fe](https://github.com/eclipse-edc/IdentityHub/tree/c46a1fef64cb53729751566e0e24fb621d2f17d2)),
most of which are gate-specific changes inherited from the EDC Connector
(listed [here](https://github.com/gate-institute/EDC-Connector)).

For a detailed view of *all* changes, see the
[diff](https://github.com/gate-institute/EDC-IdentityHub/compare/v0.15.1...gate/0.15.1?expand=1).

## Quick start

Please refer to Eclipse's
[Quick Start](https://github.com/eclipse-edc/IdentityHub/tree/v0.15.1?tab=readme-ov-file#quick-start)
guide for IdentityHub.
