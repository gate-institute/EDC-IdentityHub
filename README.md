# EDC IdentityHub

This is a fork of the [EDC IdentityHub](https://github.com/eclipse-edc/IdentityHub)
repo and contains gate-specific changes for testing and deployment purposes.

The `gate/0.14.1` branch is the main branch used for GATE deployments.
It contains changes to EDC's `v0.14.1` tag
(ref. [4c91e83](https://github.com/eclipse-edc/IdentityHub/tree/3e37de14e0bb1c6f61e692ae9882018827afb4ea)),
most of which are gate-specific changes inherited from the EDC Connector
(listed [here](https://github.com/gate-institute/EDC-Connector)).

For a detailed view of *all* changes, see the
[diff](https://github.com/gate-institute/EDC-IdentityHub/compare/v0.14.1...gate/0.14.1?expand=1).

## Quick start

Please refer to Eclipse's
[Quick Start](https://github.com/eclipse-edc/IdentityHub/tree/v0.14.0?tab=readme-ov-file#quick-start)
guide for IdentityHub.
